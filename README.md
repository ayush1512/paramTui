# ParamTUI

A modern Terminal User Interface (TUI) for managing HPC clusters via SSH.

## Features

- 📁 **File Manager** - Browse, upload, download, edit files
- 📊 **Job Dashboard** - Monitor SLURM jobs
- 🐍 **Conda Manager** - Manage conda environments
- 🧠 **Interactive Tools** - Launch interactive sessions
- 🖥️ **Resource Monitor** - Check system resources
- 📈 **Usage & Quota** - Monitor disk usage
- 🖥️ **Interactive Shell** - Access the shell

## Installation

```bash
pip install paramtui

## Run

```bash
paramtui
